### 6-2 On the Grid — Context Discussion

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Identify grid structures in real websites by annotating column count, gutter width, and intentional grid breaks.
2. Compare responsive layout decisions across mobile and desktop and evaluate whether mobile trade-offs serve users.
3. Propose a fix for one responsive design decision you identify as wrong, with a specific technical rationale.

📚 **Read before class:** Ch 4 Context, pp. 119–129

**Group — Breakpoint Audit**
Each person examines 2 websites on their phone vs. laptop. Document: What changes at each breakpoint? What's hidden on mobile? Find one responsive decision you think was wrong and propose a fix. Share findings.

**Individual — Grid Analysis**
Find 5 website screenshots that clearly use a grid system. Annotate the grid: how many columns? What's the gutter? Where does the layout break the grid intentionally?

> 🛠 **Next class:** Module 4.1, pp. 130–135 · 📌 Start On the Grid

### 6-3 Responsive Design in Figma

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Create responsive mockups at three breakpoints (375px, 768px, 1200px) using Figma auto-layout for at least one component.
2. Make and defend content hierarchy decisions specific to mobile — what is shown, what is hidden, and why.
3. Give structured layout feedback to a peer on mobile hierarchy clarity and content reordering choices.

🛠 **Work during class:** Module 4.1 *Responsive Design in Figma* (pp. 130–135)

**Individual — Responsive Figma Mockup**
Following Module 4.1: mobile (375px), tablet (768px), and desktop (1200px) versions of your On the Grid layout. Must include: navigation, hero section, content grid, footer. Use auto-layout for at least one component.

**Pair — Layout Feedback**
Swap Figma files. Give feedback on: (1) Does the mobile layout make clear hierarchy choices? (2) What content did you hide/reorder for mobile, and does that serve the user?

> 🛠 **Next class:** Module 4.2, pp. 136–144
