### 11-1 Ethical by Design — Context Discussion

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Identify 3 dark patterns on real websites, name them using established taxonomy, and explain what design choices make each possible.
2. Write a personal ethical checklist with 5 specific, testable questions to apply before shipping any design.
3. Distinguish between design that serves users and design that extracts value from users, using real examples.

📚 **Read before class:** Ch 7 Context (221–231)

**Group — Dark Pattern Taxonomy**
Teams of 3 spend 15 min on real e-commerce, subscription, or social media sites. Find and document 3 dark patterns with screenshots. Categorize using [deceptive.design](https://www.deceptive.design). Present: what design choices made the pattern possible? Who benefits?

**Individual — Designer's Ethical Checklist**
Write your personal checklist — 5 questions you'll ask yourself before shipping any design. Must be specific and testable: not "is it ethical?" but "Can a user find the unsubscribe option in under 3 clicks?"

> 🛠 **Next class:** Module 7.1 (232–239)

### 11-2 Accessibility

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Audit two websites and your own project for accessibility issues using WAVE, and produce a priority-ordered fix list.
2. Navigate a website using only a screen reader and document what worked, what failed, and how it changes your design thinking.
3. Explain why accessibility is an ethical obligation — not just a technical requirement — using evidence from your audit.

🛠 **Work during class:** Module 7.1 *Accessibility* (232–239)

**Individual — Accessibility Audit**
Following Module 7.1: audit 2 real websites AND your own Usability Test project using [WAVE](https://wave.webaim.org). Document: contrast failures, missing alt text, form label issues, heading structure. Write a priority-ordered fix list for your project.

**Pair — Screen Reader Experience**
Take turns navigating a website using only VoiceOver (Mac) or NVDA (Windows) — no looking at the screen. Partner A navigates, Partner B documents: What worked? What was confusing? Write 2 sentences on how this changes your design thinking.

> 🛠 **Next class:** Modules 7.2/7.3 (240–251)

### 11-3 Design Patterns & Accessible Implementation

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Implement ARIA labels, keyboard navigation, skip links, and color contrast fixes in a real project and validate with WAVE.
2. Evaluate 5 common design patterns for ethical implications — who benefits, who is harmed, and whether a better alternative exists.
3. Propose a better pattern for at least one evaluated pattern that achieves a legitimate design goal without the ethical cost.

🛠 **Work during class:** Module 7.2 *Design Patterns and Prototypes* (240–245) + Module 7.3 *Implementing Accessible Design* (246–251)

**Individual — Accessibility Implementation**
Implement accessibility improvements in your Usability Test project: ARIA labels, color contrast fixes, keyboard navigation, skip links. Validate with [WAVE](https://wave.webaim.org) before end of class.

**Group — Pattern Ethics Discussion**
Evaluate these patterns for ethical implications: infinite scroll, autoplay video, push notification prompts, cookie consent banners, "free trial" sign-up flows. For each: Who designed it? Who benefits? Who is harmed? Is there a better pattern?
