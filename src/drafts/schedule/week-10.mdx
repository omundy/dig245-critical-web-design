### 10-1 Brainstorming & Experimentation

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Design and code a layout under a severe constraint and explain what the constraint reveals about assumptions embedded in typical design.
2. Evaluate your own body of work with specific, reference-based strengths and growth areas — not generalizations.
3. Distinguish between experimentation as aesthetic exploration and experimentation as critical design practice.

🛠 **Work during class:** Module 6.1 *Brainstorming & Experimentation* (195–202)

**Group — Constraint-Based Design Sprint**
Teams of 3 draw a constraint card: no images / no text / no color / no hierarchy / no navigation / typography only. In 20 min: sketch then code the most compelling layout possible within that constraint. Present and discuss: what does the constraint reveal about how we usually design?

**Individual — Midpoint Portfolio Reflection**
Look at all work submitted so far. Write: 3 specific strengths, 3 specific areas to develop. Reference actual projects and choices — not "get better at CSS" but "make more intentional color decisions, as I defaulted to black and white in every project."

> 🛠 **Next class:** Module 6.2 (203–210)

### 10-2 CSS Grid & Animation

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Build a CSS Grid layout using `grid-template-areas`, named areas, and at least 3 different column spans — without Bootstrap.
2. Control animation timing using `ease`, `ease-in-out`, and `cubic-bezier` to produce specific emotional effects.
3. Describe what makes an animation feel mechanical, natural, or wrong by reference to its timing function and motion behavior.

🛠 **Work during class:** Module 6.2 *CSS Grid and Animation with CSS Transform* (203–210)

**Individual — CSS Grid Layout**
Following Module 6.2: recreate a poster or editorial layout from a reference image using CSS Grid (no Bootstrap). Must use: `grid-template-areas`, at least 3 different column spans, one named grid area.

**Pair — Animation Timing Lab**
Experiment with CSS keyframes and timing functions (`ease`, `ease-in-out`, `cubic-bezier`). Create 3 animations: one that feels mechanical, one that feels natural, one that feels wrong. Share and discuss: what makes animation feel alive vs. artificial?

> 🛠 **Next class:** Module 6.3 (211–219)

### 10-3 JS Functions, Arrays & Loops

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Write reusable JavaScript functions that accept arrays and return transformed data using `.map()`, `.filter()`, and `.reduce()`.
2. Build a program that processes a dataset and renders something visual to the DOM using loops.
3. Translate a plain-English visual algorithm into code and evaluate how faithfully the implementation matches the original intent.

🛠 **Work during class:** Module 6.3 *JavaScript Functions, Arrays, and Loops* (211–219)

**Individual — Functions & Arrays Lab**
Complete Module 6.3 exercises in [Codepen](https://codepen.io): write functions that take arrays as parameters, use `.map()`, `.filter()`, `.reduce()`. Build a small program that processes a dataset and outputs something visual to the DOM.

**Group — "Algorithm Poetry" Challenge**
Each team writes a plain-English description of a visual algorithm (e.g., "Pick a random word from a list, display it at a random position in a random color, repeat every second"). Teams swap and attempt to code each other's description. Share — how faithful is the implementation to the intent?
