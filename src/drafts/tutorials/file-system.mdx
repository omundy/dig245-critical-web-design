## Cloud-backups

Cloud-syncing services back up directories on your computer to remote servers.

Some tools are clear when you use a synced directory. But Apple (and Windows), in a constant effort to dumb-down users, obscures the division between the Finder and their iCloud Drive $ervice, [leaving it to the user](https://support.apple.com/en-us/HT201104) to know when this is a bad idea.

1. Don't save [git repositories](https://www.google.com/search?q=git+repository+icloud+issues), [Unity projects](https://docs.google.com/presentation/d/1phoKp9d7BjhM0scs78rim6DtcUGoJAy4L31eDrR3zGE/edit#slide=id.gc6cd8ea0db_0_13), and other app files in cloud-synced folders
1. Bookmark the home directory so you know the difference.





## 👉 Find your home folder 

Do the following on your (MacOS) computer

### Mac 


1. In Finder, choose View and enable the following options:
	- Show Path Bar
	- Show Status Bar
1. In the Path Bar, click Macintosh HD > Users > [your username] 
1. This your home directory!! Drag your home folder to the sidebar to bookmark it.
1. Explore other options in your MacOS Finder or Windows Explorer to see more data about your filesystem, files, etc.




### Windows

Many Windows machines (especially school- or work-managed ones) have OneDrive silently redirect your Desktop, Documents, and Pictures folders so they sync to the cloud — the same problem as iCloud Drive on Mac, above.

1. Open File Explorer.
1. In the address bar, type `%userprofile%` and press <kbd>return</kbd>. This takes you straight to your real home folder — `C:\Users\<username>\` — no matter what OneDrive has redirected.
1. Look at the left sidebar: if you see a separate **OneDrive** section listing Desktop/Documents/Pictures (with a little cloud icon on the folders), those are the *synced* versions — not the ones at `C:\Users\<username>\Desktop`. Anything you save into a OneDrive-synced folder gets uploaded, which can break git repos, Unity projects, and other apps that expect plain local files.
1. Right-click your real home folder (`%userprofile%`) and choose **Pin to Quick access**, so you can always get back to it and tell it apart from the OneDrive versions.
1. If you're not sure whether a specific folder is cloud-synced, right-click it — a synced folder's context menu will have OneDrive-specific options (like "Always keep on this device") that a plain local folder won't.
