## C.R.A.P. introduction 

We already used the "Eye Movement Test" to discover how a design can lead our eyes around a layout. CRAP design principles illustrate *why* that happens:


import { Image } from 'astro:assets';
import crapDesignContrast from '@/assets/img/crap-principles-contrast.svg';
import crapDesignRepetition from '@/assets/img/crap-principles-repetition.svg';
import crapDesignAlignment from '@/assets/img/crap-principles-alignment.svg';
import crapDesignProximity from '@/assets/img/crap-principles-proximity.svg';


<Image src={crapDesignContrast} alt="Critical Web Design cover" class="mx-auto" />

1. **Contrast** - Make different elements clearly different (size, color, weight) so the eye knows what matters most. 

<Image src={crapDesignRepetition} alt="Critical Web Design cover" class="mx-auto" />

2. **Repetition** - Repeat visual choices (colors, fonts, spacing) throughout a design so it feels unified. Treating similar content the same makes it easy to find information and navigate. 

<Image src={crapDesignAlignment} alt="Critical Web Design cover" class="mx-auto" />

3. **Alignment** - This is the spatial relationship between different elements. Line elements up with each other so nothing feels randomly placed. 

<Image src={crapDesignProximity} alt="Critical Web Design cover" class="mx-auto" />

4. **Proximity** - Group related items close together, and separate unrelated ones, to show relationships.
