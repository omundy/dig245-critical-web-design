## 🛠 Demo - Fork and Publish a Web Page

## 👉 Start Hello World

<CustomAside type="follow" reference="📚 Module 1.1 Introducing HTML (28–32)"></CustomAside>

1. Create a fork of this repository https://github.com/omundy/dig245-hello-world
1. Follow Exercise 1.2.2 to enable Github Pages (also see this [video](https://criticalwebdesign.github.io/wiki/chapter-01/1-3-using-github/#enable-github-pages)).
1. Follow the instructions to create a page about yourself, motivations for the class.
1. Required: doctype, head with title, semantic body elements (header, nav, main, footer), one image with alt text, one external link. Validate at [validator.w3.org](https://validator.w3.org) before end of class.
