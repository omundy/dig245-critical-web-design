### 7-1 Bootstrap Introduction

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Build a Bootstrap layout using only utility classes — navbar, hero, 3-column card grid, and footer — without writing custom CSS.
2. Identify Bootstrap components on 5 live websites and articulate what visual homogeneity across the web means for design culture.
3. Explain the difference between Bootstrap's utility-first approach and custom CSS, and where each is appropriate.

🛠 **Work during class:** Module 4.2 *Bootstrap Introduction* (pp. 136–144)

**Individual — Bootstrap Component Build**
Following Module 4.2: [Bootstrap](https://getbootstrap.com) navbar, hero section, 3-column card grid, footer. No custom CSS yet — Bootstrap utilities only. Goal: understand what Bootstrap gives you before you customize it.

**Group — "Bootstrap Bingo"**
Each team gets a bingo card with Bootstrap component names (navbar, badge, accordion, modal, spinner, etc.). Browse 5 live websites and check off what you identify. Debrief: How many sites use Bootstrap? What does that homogeneity mean for web culture?

> 🛠 **Next class:** Module 4.3, pp. 145–152

### 7-2 Bootstrap Grid System

### Learning objectives

{/* By the end of this session you will be able to: */}
1. Build a multi-breakpoint Bootstrap grid layout with correct column counts, breakpoint classes, and no improper nesting.
2. Diagnose and fix a broken Bootstrap layout by reading HTML structure and explaining what was wrong.
3. Use DevTools to inspect the Bootstrap grid overlay and verify column structure matches the intended design.

🛠 **Work during class:** Module 4.3 *The Bootstrap Grid System* (pp. 145–152)

**Individual — [On the Grid](https://github.com/omundy/dig245-on-the-grid) Coding Sprint**
Follow Module 4.3 to build your On the Grid layout. Focus: get all content in the correct column structure before adding any custom styles. Use DevTools to inspect the grid in action.

**Pair — Grid Debug Challenge**
Each partner creates a "broken" Bootstrap layout (wrong column counts, missing breakpoints, improper nesting). Swap and fix. Explain out loud what was wrong.
