### 5-1 File Paths, Images & Pseudo-classes

**Learning objectives:** By the end of this session you will be able to:
1. Add CSS pseudo-classes (hover, focus, active) to interactive elements and explain what each state change communicates to the user.
2. Use CSS transitions to give state changes a temporal dimension and articulate the emotional effect intended.
3. Analyze images that communicate brand values without text and identify the ideological assumptions each makes about its viewer.

🛠 **Work during class:** Module 3.2 *File Paths, Images, and Pseudo-Classes* (pp. 99–111)

**Individual — CSS Pseudo-class Lab**
Follow Module 3.2 to add hover states, focus styles, and CSS transitions to your Unbranding project. Every interactive element should have a visible state change. Note what feeling each transition conveys.

**Group — "Image Speaks" Activity**
Teams of 3 find 5 images that communicate a brand value WITHOUT any text (freedom, trust, innovation, rebellion). Present choices. Discussion: How do images carry ideology? What assumptions do they make about the viewer?

### 5-2 Web Fonts & JavaScript Events

**Learning objectives:** By the end of this session you will be able to:
1. Load and implement a web font pairing from Google Fonts with a written rationale connecting typographic choices to conceptual intent.
2. Diagnose and fix broken JavaScript event handlers by reading code critically without executing it first.
3. Build a Codepen demonstrating a typographic hierarchy (headline, subheadline, body, CTA) using a chosen font pairing.

🛠 **Work during class:** Module 3.3 *Web Fonts & JavaScript Events* (pp. 112–117)

**Individual — Typography Pairing**
Choose 2 [Google Fonts](https://fonts.google.com) that create meaningful contrast. Build a Codepen showing: headline, subheadline, body, CTA using your pairing. Write a 50-word rationale: why these fonts serve your Unbranding concept.

**Pair — JS Event Debugging Challenge**
Given a starter Codepen with 3 broken event handlers: Partner A debugs, Partner B reads and spots issues without touching the keyboard. Switch after each fix.
