## AI Ground rules

Now that you have foundational knowledge in HTML CSS JS we can start incorporating AI tools, with the following rules:

1. **Audit Every Output**: AI is trained on massive projects by professionals. Never use code unless you can explain line-by-line what it does.
1. **Not a magic bullet**: Treat AI like a junior assistant—it offers suggestions, but you direct the action.
1. **Be transparent** about how AI informed your project. Attribute it with a 1-line code comment whenever AI helped solve a bug or structure a feature.

## 6. AI Critique Your Regenerative Prototype

Create a prompt using this framework: *"Role + Context + Goal + Constraint"*. For example, "Act as a professional chef in a vegan restaurant. Review this carrot cake recipe to make sure it is dairy and gluten free."

For your project...

1. Give the AI a role: `Act as a front-end developer.`
1. Provide context: `The Regenerative assignment asks me to create a web page that can generate new iterations of itself based on some changeable data source. My idea is ________`
1. Ask for a plan `Give me a plan to help structure this document. `
1. Finish with constraints: `Keep it simple. I will design the layout myself.`
