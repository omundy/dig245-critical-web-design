## 👉 How to Set Up a New Web Project with Git

<CustomAside type="excerpt" reference="Exercise 1.2.1"></CustomAside>

This exercise establishes best practices for setting up a new website project, including
the index.html page, and tracking and publishing with Git. Document every step you get stuck on — this becomes your troubleshooting log for the semester.

1. Login or create an account at https://github.com 
2. Click the plus button at the top right of your page to create a New Repository.
3. Name the repository `first-website` and enable `Add README`.
4. Click “Create repository.”
5. Click “Add file” to create a new file in your `first-website` repo, and name it `index.html`.
6. Add the html, head, and body elements that define the structure of an HTML file. Your code should look like the following:

```html
<html>
  <head>
    <title>Hello, World!</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
  </body>
</html>
```
