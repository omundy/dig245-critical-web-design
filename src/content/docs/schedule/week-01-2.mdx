## Learning objectives

{/* By the end of this session you will be able to: */}

1. Set up a complete web development environment including GitHub, Codespaces, and Codepen.
2. Document technical setup steps and blockers in a structured troubleshooting log.
3. Identify and resolve at least one peer's setup problem through collaborative troubleshooting.






## 👉 Work during class

- 📚 Module 0.2 _Technical Requirements_ (pp. 11–15)

**Individual — Setup Checklist**
Follow Module 0.2 to set up your environment: GitHub account, Codespaces, Codepen, course tools. Document every step you get stuck on.

**Pair — Peer troubleshooter**
Find one person who got something working that you didn't, and one person you can help. Spend 15 min solving each other's setup issues. Report unresolved blockers to the class.
