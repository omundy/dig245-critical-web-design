## Share and Diagram Regenerative Ideas


**Group — Share Regenerative Project Concepts**

Share your brainstorming work (Haiku) and concept (statement) for the [Regenerative](https://github.com/omundy/dig245-regenerative) project. Peer feedback using 3 questions: 

1. Is the generative system clear? 
1. What is the aesthetic goal? 
1. What's technically risky and needs prototyping first?


**Individual — Plan Your Prototype**

1. Diagram your idea - Where is the loop? Describe the user experience.
1. Write pseudocode describing how you'll create it



```
Create global variables
Store a reference to the main HTML element
Create generate() function
Reset variables, remove previous elements from the page
Repeat the following for a random number of boxes
Generate a random size, position, and color
Insert the boxes into the page as HTML
Add listener to call generate() on page load or when user clicks
Create helper functions
Return a random number between min and max
Return a random color
```

Pseudocode example from Ch8 (p.270) for [Generative Arp](https://criticalwebdesign.github.io/book/08-generative-design/8-3/)
