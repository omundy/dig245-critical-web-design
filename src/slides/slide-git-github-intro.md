Imagine you want to update a website with a new feature.

---

<section id="fragments">
  <span>You aren’t sure if you will like the changes you made, so you duplicate your project folder. </span>
  <span class="fragment">This way you can go back to the previous files if you (or maybe your client) change your mind. </span>
</section>

---

You make all of your new edits in the duplicate files, so if you don’t like them you can just delete that folder to “undo.”

---

Your system works so well (since you practice iterative design!) you make a second and third iteration of the new feature to test those, too.
